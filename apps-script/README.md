# 직원 전용 페이지 설정 (taxdg.com/staff/)

직원 화면(`staff/`)은 GitHub Pages에 올라가고, 로그인·업체 자료 저장·안내문·공지는
대표님 구글 계정의 Apps Script(무료)와 구글 시트가 맡습니다. 비밀번호는 코드나 이 저장소에 넣지 않고
Apps Script의 "스크립트 속성"에만 보관합니다. 업체 이름 같은 자료도 저장소에는 없고 구글 시트에만 있습니다.

메뉴: **업체별 기장**(`staff/clients.html`), 안내문·템플릿, 공지·매뉴얼, 휴가 신청(기존 구글 폼 연결).

## 처음 한 번만 하는 설정 (이미 해 두셨다면 3번부터)

1. **구글 시트**: 이미 쓰는 시트를 그대로 쓰면 됩니다. 처음이면 sheets.new 에서 새 시트를 만듭니다.
   직원과 공유하지 않아도 됩니다(직원은 홈페이지에서만 씁니다).
2. **스크립트 붙여 넣기**: 시트 메뉴 확장 프로그램 → Apps Script. 열린 `Code.gs`의 내용을 모두 지우고
   이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(디스크 아이콘)합니다.
3. **스크립트 속성**: 왼쪽 톱니바퀴(프로젝트 설정) → 맨 아래 "스크립트 속성"에서 아래를 넣고 저장합니다.

   | 속성 | 값 |
   |---|---|
   | `SESSION_SECRET` | 아무 긴 문자열(30자 이상, 외울 필요 없음) |
   | `STAFF_USERS` | 직원별 비밀번호. 한 줄에 `이름:비밀번호` (아래 예시) |
   | `STAFF_PASSWORD` | 모두가 같이 쓰는 비밀번호. `STAFF_USERS`가 없을 때만 쓰입니다 |
   | `LEAVE_FORM_URL` | (선택) 휴가 신청 구글 폼 링크 |

   `STAFF_USERS` 예시 (이 이름들이 곧 직원 명단입니다. 소스 코드에는 직원 이름이 없고, 비밀번호에 쉼표는 쓰지 마세요):
   ```
   직원1이름:비밀번호1
   직원2이름:비밀번호2
   ```
   로그인 화면에는 이름 칸이 없고 비밀번호만 입력합니다. 비밀번호가 그 사람을 가리키므로 **직원마다 서로 다른
   비밀번호**여야 하고(8자 이상 권장), 같은 비밀번호가 둘 이상이면 로그인이 거절됩니다. 직원이 바뀌면 이 속성만
   고치면 됩니다. `STAFF_USERS`가 없으면 공용 비밀번호(`STAFF_PASSWORD`)로 이름 없이 들어옵니다.
4. **권한 승인**: 편집기 위쪽 함수 목록에서 `setup`을 고르고 실행 → 권한 검토 → 대표님 계정 선택 →
   "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → (안전하지 않음)으로 이동 → 허용.
   실행하면 시트에 `업체`, `업체자료`, `수정이력` 탭이 만들어집니다.
5. **웹 앱 배포**: 처음이면 배포 → 새 배포 → 유형 선택(톱니) → 웹 앱. 실행 사용자 **나**, 액세스 **모든 사용자**.
   나오는 주소(`…/exec`)를 `staff/config.js`에 붙여 넣습니다(이미 되어 있으면 건너뜁니다).
   **코드를 고친 뒤에는 새 배포가 아니라 배포 → 배포 관리 → 연필 → 새 버전**으로 올려야 주소가 바뀌지 않습니다.

## 업체별 기장

- 업체 목록, 기본정보, 부가세·소득세·법인세 체크리스트, 세금예측이 모두 이 시트에 저장됩니다.
  화면에서 적으면 잠시 뒤 자동 저장되고(오른쪽 위에 "저장됨" 표시), `수정이력` 탭에 누가·언제·무엇을 고쳤는지 쌓입니다.
- **업체 한꺼번에 넣기**: 오른쪽 위 버튼 → 엑셀에서 `업체명 / 구분(법인·개인) / 담당 / 기장·신고 / 비고` 칸을 복사해 붙여넣습니다.
  이미 있는 업체명은 건너뜁니다.
- **엑셀로 내보내기**: 오른쪽 위 버튼 → 업체목록, 기본정보, 부가세, 소득세, 법인세, 세금예측 시트가 나뉜 `.xlsx` 파일이 내려받아집니다.
- 한 화면(예: 한 업체의 한 회차)에 적는 내용은 5만 자 안쪽이어야 저장됩니다(메모를 아주 길게 적으면 안내가 뜹니다).
- 같은 업체를 두 명이 동시에 고치면 마지막으로 저장한 사람의 내용이 남습니다(화면별로). 업체를 열 때마다 최신 내용을 다시 불러옵니다.

## 안내문·템플릿, 공지·매뉴얼

글은 시트의 `안내문템플릿`, `공지매뉴얼` 탭에 저장됩니다(탭은 처음 열 때 자동으로 생기고, 안내문 기본 7개가 들어갑니다).
작성자는 로그인한 이름으로 자동 입력됩니다.

**휴가 신청**은 기존 구글 폼으로 연결됩니다. 폼 응답 시트·캘린더 반영은 지금 쓰는 설정 그대로입니다.
`LEAVE_FORM_URL`에 폼의 응답용 링크(폼 화면 오른쪽 위 **보내기** → 링크 아이콘)를 넣으면 휴가 신청 탭에 버튼이 나타납니다.

## 이전 법령 검색·AI 정리

직원 페이지에서 법령 검색, AI 정리, 질문 내역 기능은 뺐습니다(코드는 저장소 기록에 남아 있습니다).
시트의 `질문내역` 탭과 스크립트 속성 `LAW_OC`, `GEMINI_API_KEY` 등은 이제 쓰이지 않으니 지우셔도 됩니다.
