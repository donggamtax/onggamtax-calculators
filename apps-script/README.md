# 직원 전용 법령 검색 설정 (taxdg.com/staff/)

직원 화면(`staff/`)은 지금처럼 GitHub Pages에 올라가고, 비밀번호 확인·법제처 조회·질문 내역 저장은
대표님 구글 계정의 Apps Script(무료)가 맡습니다. 질문 내역은 구글 시트에 한 줄씩 쌓입니다.
비밀번호와 법제처 인증값은 코드나 이 저장소에 넣지 않고 Apps Script의 "스크립트 속성"에만 보관합니다.

## 처음 한 번만 하는 설정

1. **법제처 Open API 인증값(OC) 확인**: open.law.go.kr 로그인 → 마이페이지 → Open API 신청 내역.
   신청할 때 쓴 이메일의 @ 앞부분인 경우가 많습니다. 법령, 판례, 법령해석례, 조세심판원 특별행정심판례,
   중앙부처 1차 해석(국세청·기획재정부) 항목이 신청되어 있어야 해당 검색이 나옵니다.
2. **구글 시트 만들기**: sheets.new 에서 새 시트를 만들고 이름을 "직원 법령검색"으로 바꿉니다.
   이 시트는 직원과 공유하지 않아도 됩니다(직원은 홈페이지에서만 씁니다).
3. **스크립트 붙여 넣기**: 시트 메뉴 확장 프로그램 → Apps Script. 열린 `Code.gs`의 내용을 모두 지우고
   이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(디스크 아이콘)합니다.
4. **비밀 값 넣기**: 왼쪽 톱니바퀴(프로젝트 설정) → 맨 아래 "스크립트 속성" → 속성 추가로 세 개를 넣고 저장합니다.

   | 속성 | 값 |
   |---|---|
   | `LAW_OC` | 1의 인증값 |
   | `STAFF_PASSWORD` | 직원들이 쓸 비밀번호 |
   | `SESSION_SECRET` | 아무 긴 문자열(30자 이상, 외울 필요 없음) |

5. **권한 승인**: 편집기 위쪽 함수 목록에서 `setup`을 고르고 실행 → 권한 검토 → 대표님 계정 선택 →
   "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → (안전하지 않음)으로 이동 → 허용.
   본인이 만든 스크립트라 나오는 안내입니다. 실행 기록에 세 값이 모두 "있음"이면 됩니다.
6. **웹 앱으로 배포**: 오른쪽 위 배포 → 새 배포 → 유형 선택(톱니) → 웹 앱.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   배포를 누르면 나오는 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
   "모든 사용자"여도 비밀번호 없이는 아무것도 볼 수 없습니다.
7. **홈페이지에 주소 넣기**: 이 저장소의 `staff/config.js`에서 따옴표 안에 6의 주소를 붙여 넣고 저장(커밋)합니다.
   이 주소는 비밀 값이 아니라서 공개 저장소에 있어도 됩니다. 잠시 뒤 https://taxdg.com/staff/ 에서 로그인할 수 있습니다.

## AI 정리(구글 Gemini) 켜기

"AI로 정리하기" 버튼을 누르면 Gemini가 법제처 검색·원문 열람을 직접 여러 번 하면서 근거를 모은 뒤 결론·설명·근거를 정리합니다(1~2분).
정확도를 높이려면 `GEMINI_MODEL`을 `gemini-pro-latest`로 두는 것을 권합니다.
Gemini 앱 유료 구독과 API 키는 별개라서 키를 따로 만들어야 합니다.

1. aistudio.google.com 접속 → 왼쪽 아래 **Get API key** → **API 키 만들기** → 키 복사.
2. 같은 화면에서 결제(Billing)를 연결하면 유료 등급이 됩니다. 유료 등급은 입력 내용을 구글이 학습에 쓰지 않습니다.
   결제를 연결하지 않은 무료 등급은 입력 내용이 서비스 개선에 쓰일 수 있으니 고객 정보는 넣지 마세요.
3. Apps Script 스크립트 속성에 `GEMINI_API_KEY` = 복사한 키 를 추가하고 저장합니다. 정리 모델은 기본이 Gemini Pro(`gemini-pro-latest`)입니다.
   (정리 모델을 바꾸려면 `GEMINI_MODEL`. 기본값 `gemini-flash-latest`, 더 정확한 정리는 `gemini-pro-latest`.
   검색어 고르기는 늘 빠른 모델을 씁니다.)

## 직원 메뉴 (자주 묻는 질문·안내문·공지·휴가)

각 메뉴의 글은 이 시트에 탭으로 저장됩니다. 탭은 메뉴를 처음 열 때 자동으로 생깁니다.

| 메뉴 | 시트 탭 |
|---|---|
| 자주 묻는 질문 | 자주묻는질문 |
| 안내문·템플릿 | 안내문템플릿 (처음 열 때 기본 안내문 7개가 들어갑니다) |
| 공지·매뉴얼 | 공지매뉴얼 |
| 휴가 신청 | 휴가신청 |

**휴가 승인·반려**: 시트의 "휴가신청" 탭에서 해당 줄의 "상태" 칸을 `승인` 또는 `반려`로 바꾸면 됩니다.
"처리메모" 칸에 적은 내용은 직원 화면에 함께 보입니다. 처리된 신청은 직원이 취소할 수 없습니다.

## 바꿀 때

- **비밀번호 변경**: 스크립트 속성의 `STAFF_PASSWORD`만 고치면 바로 적용됩니다. 이미 로그인한 사람까지
  끊으려면 `SESSION_SECRET`도 바꿉니다.
- **코드 수정**: `Code.gs`를 고친 뒤 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포.
  "새 배포"로 하면 주소가 바뀌니 7을 다시 해야 합니다.
- **질문 내역**: 시트의 "질문내역" 탭에서 바로 보거나 엑셀로 내려받을 수 있습니다. 칸 순서는 바꾸지 마세요.

## 무료 한도

개인 구글 계정 기준 외부 호출(UrlFetch)은 하루 2만 회입니다. 한 번 검색할 때 고른 종류 수만큼(최대 6회) 쓰므로
직원 몇 명이 쓰기에는 충분합니다.
